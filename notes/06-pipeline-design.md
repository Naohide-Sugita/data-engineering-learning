## 6-1. パイプライン構成

- データがどこから来て、どこで加工され、どこへ保存されるかという全体構成
- 例：`Pub/Sub → Dataflow → BigQuery`

## 6-2. オーケストレーション

- 複数の処理について、実行順序・依存関係・スケジュールなどを管理する

## 6-3. Cloud Composer / Workflows

### Cloud Composer
- Google CloudのマネージドApache Airflow
- DAGで複数タスクの実行順序・依存関係・スケジュールを管理する
- Cloud Storage、Dataproc、BigQueryなど複数サービスを組み合わせた処理に向く
- 既存Airflow DAGを移行・再利用しやすい
- 「複雑な依存関係 + Airflow/DAG」→ Cloud Composer

### Workflows
- Google CloudサービスやHTTP APIを順番に呼び出すワークフローを構築する
- Airflowほどのデータパイプライン管理が不要なサービス連携に向く

## 6-4. Dataform

- BigQuery上のSQLベースの変換処理を管理する
- テーブル間の依存関係を管理できる
- Gitと統合してSQL変換をバージョン管理できる
- 「BigQuery + SQL変換 + 依存関係 + Git」→ Dataform

## 6-5. スケジュール実行

- Cloud Scheduler：cronのように決められた日時・間隔で処理を起動する

## 6-6. イベント駆動処理

- 何かのイベントをきっかけに処理を開始する方式
- 例：Cloud Storageへのファイル到着、Pub/Subメッセージ受信
- EventarcでイベントをCloud Runなどへルーティングできる

## 6-7. DAG

- Directed Acyclic Graph
- タスクの依存関係と実行順序を表す
- 例：`A完了 → B開始 → C開始`
